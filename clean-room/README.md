# Clean-room implementation boundary

No remake has been implemented. This directory is intentionally limited to
planning and boundary documentation.

A future implementation belongs here and should be based on the behavioral
specification in `research/`, not by copying decompiled ActionScript. Original
SWFs, decompiler output, and extracted assets remain outside this directory.

The proposed architecture, TDD workflow, headless simulation design, and
delivery sequence are documented in [`PLAN.md`](PLAN.md).
