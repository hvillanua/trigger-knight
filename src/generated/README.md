# Generated production and research source

Generated production files belong here only when their inputs are implementation
files or approved original/separately licensed assets with recorded provenance.
Commit the generator and start text outputs with a `@generated from approved
input` comment. Generated behavioral research and decompiler outputs remain
under `decompiled/` or `exports/` and cannot be imported by the production
application. An extracted original asset must still be staged under
`src/assets/` with provenance before production use.
